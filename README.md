# 輕量純文字題庫測驗系統 (Quiz App)

一個完全**無須後端資料庫**、**零編譯環境依賴**的純前端題庫測驗系統。  
題目採用純文字 Markdown 格式維護，支援 GitHub Pages 一鍵託管，並於用戶端即時解析。

---

## ✨ 系統特色
- **手打友善**：擺脫嚴格的 JSON 括號與跳脫符號，純文字自然書寫。
- **按需載入**：在設定面板勾選單元後，才即時 fetch 對應的題庫檔案，省流量且極速。
- **豐富排版支援**：
  - 數學式：LaTeX 語法（由 KaTeX 極速渲染）。
  - 排版結構：Markdown 表格、圖片（`images/` 目錄）、粗體、引用。
- **動態算分**：免去每題手動配分，依 `(答對數 / 總題數) * 100` 自動結算成績。

---

## 📝 題目書寫規範速查手冊

題目檔統一存放在 `questions/<科目名稱>/` 目錄下，副檔名為 `.md`。  
**每道題目之間請務必使用 `---` 進行區隔**。

### 1. 欄位規範說明

| 標籤 | 說明 | 必填 | 預設值（未填寫時） |
| :--- | :--- | :---: | :--- |
| `Q:` | 題目內容（支援 Markdown 圖片、表格與 LaTeX 公式） | **必填** | 無（缺則視為無效題） |
| `ANS:` | 正確答案 | **必填** | 無（缺則視為無效題） |
| `A.` ~ `D.` | 選項內容（若是非題/填充題則完全不需寫） | 選填 | **跳過不建立選項（給 `null`）** |
| `DIFF:` | 難度，可填 `簡單`、`中等`、`困難` | 選填 | `中等` |
| `EXP:` | 詳解說明（支援 Markdown 與 LaTeX 公式） | 選填 | 空字串 |
| `TYPE:` | 題型宣告（一般情況系統會自動判斷，可不填） | 選填 | **智慧自動判定** |

> **題型自動判定邏輯**：
> - 有填選項 `A.`、`B.` $\rightarrow$ 自動判為 **單選題 (`SINGLE_CHOICE`)**
> - 無選項且答案為 `O` / `X` / `T` / `F` $\rightarrow$ 自動判為 **是非題 (`TF`)**
> - 無選項且答案為文字 $\rightarrow$ 自動判為 **填充題 (`FILL`)**

### 2. 題目範例

#### 範例 A：單選題（包含 LaTeX 數學公式與解析）
```text
DIFF: 困難
Q: 已知平面向量 $\vec{a} = (1, \sqrt{3})$，則其方向角 $\theta$ 為多少？
A. $30^\circ$
B. $45^\circ$
C. $60^\circ$
D. $90^\circ$
ANS: C
EXP: $\tan\theta = \frac{\sqrt{3}}{1} = \sqrt{3}$，且在第一象限，故 $\theta = 60^\circ$。
