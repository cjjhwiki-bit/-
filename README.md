# 📚 專業題庫測驗系統 (Quiz App)

一個完全**無須後端資料庫**、**零依賴編譯環境**的純前端現代化題庫系統。  
出題採用純文字 Markdown 格式，支援 GitHub Pages 一鍵託管，並於用戶端即時解析與批改。

---

## ⚠️ 出題第一天條：題目分隔線（最重要！）

> **每一道題目之間，務必單獨一行寫上三個減號：`---`**

### 為什麼一定要加 `---`？
* 解析器是透過 `---` 來辨認「這題已經結束，下一題開始了」。
* **如果漏掉 `---`**：系統會把整份檔案當成「同一道超長題目」，後面題目會覆蓋前面題目，最後導致**整份檔案被判定為無效題**！

#### ✅ 正確示範：
```text
Q: 臺灣的第一高峰是哪座山？
A. 玉山
B. 雪山
ANS: A
---
Q: 臺灣最高的山脈是中央山脈。
ANS: X
---
❌ 錯誤示範（只空行、沒加 ---）：
code
Text
Q: 臺灣的第一高峰是哪座山？
A. 玉山
B. 雪山
ANS: A

Q: 臺灣最高的山脈是中央山脈。   <-- 漏掉 ---，整份題庫會損毀無法載入！
ANS: X

📝 題目書寫標籤手冊
系統支援全形與半形標點（Q: 或 Q：、ANS: 或 ANS： 均可），標籤均不區分大小寫。
標籤	說明	必填	預設值（沒寫時）
---	題目結束分隔線	是	缺此符號題目會黏在一起損壞
Q:	題目內文（支援 Markdown、表格、圖片、LaTeX）	是	無（缺則視為無效題）
ANS:	正確答案	是	無（缺則視為無效題）
A.~Z.	選項內容（A、B、C、D、E 任選）	否	若沒寫直接略過，不建立選項
DIFF:	難度，可填：簡單、中等、困難	否	中等
EXP:	詳解說明（支援公式與多行換行）	否	空字串
TYPE:	題型宣告（系統會自動判定，通常不用填）	否	智慧自動判定
題型自動判定機制：
有寫選項且答案為多個字母（如 ANS: A, C 或 ANS: ACD） 
→
→
 多選題 (MULTI_CHOICE)
有寫選項且答案為單一字母（如 ANS: A） 
→
→
 單選題 (SINGLE_CHOICE)
沒寫選項且答案為 O / X / T / F / 對 / 錯 
→
→
 是非題 (TF)
沒寫選項且答案為文字 
→
→
 填充題 (FILL)
💡 各類題型撰寫範例大全
1. 標準單選題（含難度、LaTeX 數學公式、詳解）
code
Text
DIFF: 困難
Q: 已知平面直角坐標系中，向量 $\vec{a} = (1, \sqrt{3})$，則其方向角 $\theta$ 為多少？
A. $30^\circ$
B. $45^\circ$
C. $60^\circ$
D. $90^\circ$
ANS: C
EXP: $\tan\theta = \frac{\sqrt{3}}{1} = \sqrt{3}$，且位於第一象限，故 $\theta = 60^\circ$。

🗂️ 目錄設定檔 (manifest.json) 撰寫指南
manifest.json 採用**扁平化清單（Flat Array）**格式，每一筆單元就是一個物件。
格式範例：
code
JSON
[
  {
    "grade": "九年級",
    "subject": "理化",
    "edition": "翰林",
    "id": "9-pc-h-1",
    "name": "第一單元:直線運動",
    "file": "questions/九年級/理化/翰林/第一單元-直線運動.txt"
  },
  {
    "grade": "九年級",
    "subject": "理化",
    "edition": "翰林",
    "id": "9-pc-h-2",
    "name": "第二單元:牛頓運動定律",
    "file": "questions/九年級/理化/翰林/第二單元-牛頓運動定律.txt"
  }
]
⚠️ JSON 避坑注意事項：
最外層必須是中括號 [ 與 ]，不能是大括號 {}。
不能包含任何註解（不能寫 //）。
最後一個物件結尾不能有逗號 ,。
"file" 路徑檔名絕對不要用冒號 :（請使用減號 - 或底線 _，避免 Windows 或 URL 錯誤）。
🎮 系統測驗功能特色
四層層級連動選單：年級  科目  版本 單元（支援即時關鍵字搜尋）。
隨機題數與計時器：可指定隨機抽 5、10、20 題，並支援正數計時或 10～60 分鐘倒數計時。
答題刪去法（✕）：點擊選項旁的「✕」按鈕，立即在選項加上刪除線並反灰禁選。
隨身手寫計算紙（Scratchpad）：支援觸控筆手寫、橡皮擦與一鍵清空，供隨時計算草稿。
題號快選表與待檢查標記（🚩）：隨時標記不確定的題目，點擊題號面板即時跳題。
一鍵交卷自動批改：自動比對答案、依題數計算百分制總分，並展示全題型的完整詳解與公式。
